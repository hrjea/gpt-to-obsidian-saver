## Project Description

GPT to Obsidian Saver is a Chrome extension that saves ChatGPT answers and HTML learning materials into Obsidian as local Markdown notes. It supports Obsidian URI mode and optional native-helper mode for direct vault writes and HTML attachments.

## Maintainer Role

Maintainer and release manager for the public GitHub project.

## Problem Solved

Users who study or research with ChatGPT often need local, durable notes in Obsidian. This project provides a local-first save flow for Markdown answers and downloadable HTML learning materials.

## Technical Maturity

- Manifest V3 Chrome extension.
- Content script and background service worker.
- Chrome Native Messaging helper.
- macOS native-helper installer.
- Windows native-helper implementation marked Experimental.
- Release validation and packaging scripts.
- Privacy, security, troubleshooting, and native messaging documentation.

## Current Distribution Model

GitHub Releases only. Users download ZIP files and install the extension with Chrome Load unpacked. The project is not distributed through the Chrome Web Store.
